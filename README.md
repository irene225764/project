# CampusFix

CampusFix is a campus facilities issue-reporting app. The initial project skeleton includes a React/Vite client and an Express/Mongoose API.

## Development

1. Install dependencies with `npm install`.
2. Copy `server/.env.example` to `server/.env` and configure MongoDB and a private JWT secret.
3. Copy `client/.env.example` to `client/.env` if the API URL differs from its local default.
4. Run both apps with `npm run dev`.

The client runs at `http://localhost:5173`; the API runs at `http://localhost:5000`.
